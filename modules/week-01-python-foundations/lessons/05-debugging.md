# Lesson 05: Debugging Workflows

## Learning Objectives
- Diagnose runtime errors from stack traces.
- Reproduce failures consistently.
- Apply targeted fixes and re-test.

## Core Concepts
- Read tracebacks from bottom to top.
- Differentiate syntax, type, and value errors.
- Use print/log statements to inspect state.

## Debugging Checklist
1. Reproduce with smallest input.
2. Capture exact error text.
3. Inspect variable state before failure.
4. Fix one issue at a time.
5. Re-run happy path and failure path.

## Practice Tasks
1. Intentionally break a function and fix it.
2. Add two debug prints, then remove them after fix.

## Exit Criteria
You can resolve common Python runtime errors without guesswork.
