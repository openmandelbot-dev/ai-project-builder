# Lesson 01: Python Basics

## Learning Objectives
- Understand Python data types and variable assignment.
- Use arithmetic, comparison, and logical operators.
- Read and write simple expressions with predictable output.

## Core Concepts
- Primitive types: `int`, `float`, `str`, `bool`.
- Variable naming conventions and reassignment.
- Type conversion with `int()`, `float()`, and `str()`.

## Guided Example
```python
name = "Ava"
age = 21
is_builder = True
print(name, age, is_builder)
```

## Practice Tasks
1. Create 5 variables of different types.
2. Convert a string number to integer and add 10.
3. Write expressions that return `True` and `False`.

## Exit Criteria
You can explain type differences and predict expression results before running code.
