# Lesson 02: Control Flow and Functions

## Learning Objectives
- Build conditional logic using `if/elif/else`.
- Iterate with `for` and `while` loops.
- Create reusable functions with parameters and returns.

## Core Concepts
- Branching for decision-making.
- Loop control with `break` and `continue`.
- Function signatures and return contracts.

## Guided Example
```python
def grade(score: int) -> str:
    if score >= 90:
        return "A"
    if score >= 75:
        return "B"
    return "C"
```

## Practice Tasks
1. Write a function that checks if a number is even.
2. Loop through a list and print only positive values.
3. Build a menu loop that exits on `q`.

## Exit Criteria
You can turn repeated logic into functions and control loop behavior safely.
