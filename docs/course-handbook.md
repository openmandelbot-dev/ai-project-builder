# Course Handbook

## Course Title
Python for AI Builders

## Course Purpose
This course trains builders to develop practical Python skills for real-world AI workflows. The emphasis is on execution: writing scripts, integrating APIs, handling data reliably, and shipping automation.

## Learning Outcomes
By course completion, learners will be able to:
- Apply core Python constructs to production-oriented scripts.
- Consume public REST APIs and parse JSON payloads safely.
- Use virtual environments and debugging workflows effectively.
- Build and document utility scripts for file operations and data extraction.
- Deploy and monitor a scheduled automation task with GitHub Actions.

## Prerequisites
- Basic command-line familiarity.
- No prior Python experience required.

## Delivery Model
- 10-day guided path over 2 weeks.
- Daily lesson + hands-on implementation.
- Weekly labs mapped to shipping artifacts.
- Final milestone validated with an automated run.

## Success Criteria
A learner is considered successful when they can independently run and explain each deliverable, and the milestone workflow executes without manual intervention.
