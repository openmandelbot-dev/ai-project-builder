# Assessments and Completion Standards

## Assessment Model
- Continuous assessment via four project deliverables.
- Final milestone demonstrating automated execution.

## Project Rubric (Per Project)
- Correctness (40%): Meets all functional requirements.
- Reliability (25%): Handles invalid input and runtime failures.
- Code Quality (20%): Readable, modular, and maintainable.
- Documentation (15%): Clear run instructions and usage examples.

## Milestone Rubric
- Deployment correctness: Workflow executes successfully.
- Observability: Output artifact and timestamps are generated.
- Operational quality: API failure handling is explicit and predictable.

## Required Evidence for Completion
- All scripts run as documented.
- Milestone workflow completes from manual trigger and scheduled run.
- Repository includes updated docs and clean structure.
