# Week 1 Modules

## Module 1: Python Fundamentals
- Variables and primitive types
- Loops and control flow
- Functions and parameters
- Basic exceptions

## Module 2: OOP Basics
- Define classes and methods
- Use constructor state for reusable behavior
- Keep methods focused and testable

## Module 3: Working with APIs
- Build URLs with query params
- Make HTTP requests with `requests`
- Check response status and handle failures

## Module 4: JSON Parsing
- Read nested keys safely with `dict.get`
- Extract only required fields
- Normalize output for CLI display

## Module 5: Debugging Basics
- Read traceback from bottom up
- Reproduce with smallest failing input
- Add targeted debug logging

## Practice Targets
- Solve 2-3 mini tasks per module.
- Spend at least 30 minutes/day on implementation, not just reading.
