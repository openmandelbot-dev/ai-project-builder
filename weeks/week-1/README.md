# Week 1: Python Foundations for AI Builders

## Week Goal
Build Python fluency and API literacy so you can create useful AI-adjacent tools quickly.

## Daily Plan (5 Days)

### Day 1
- Python syntax, variables, and data types.
- Practice: 10 short problems.

### Day 2
- Conditionals, loops, and functions.
- Practice: input validation and reusable helper functions.

### Day 3
- OOP basics (classes, objects, methods).
- Environment setup with `venv`.

### Day 4
- REST APIs: HTTP `GET`, status codes, and timeouts.
- Parse nested JSON safely.

### Day 5
- Debugging workflow: stack traces, logs, and quick triage.
- Ship two projects.

## Week 1 Deliverables
- `projects/cli_calculator.py`
- `projects/weather_fetcher.py`

## Definition of Done
- You can explain how your scripts handle bad input and runtime errors.
- Weather script runs from CLI flags and prints structured output.
