# Project Briefs

## 1) CLI Calculator

### Goal
Build an interactive command-line calculator supporting `+`, `-`, `*`, and `/`.

### Requirements
- Read two numbers and an operator from user input.
- Validate bad input and division by zero.
- Loop until user quits.

### Stretch
- Add percentage, power, and history.

---

## 2) API-Based Weather Fetcher

### Goal
Fetch weather data from a public API and print a simple forecast.

### Requirements
- Accept latitude/longitude from command line.
- Request data via HTTP.
- Parse JSON and print temperature + weather code.

### Stretch
- Add city lookup and output formatting.

---

## 3) File Automation Script

### Goal
Automate file organization in a local directory.

### Requirements
- Scan a folder.
- Sort files into subfolders by extension.
- Print summary report.

### Stretch
- Add dry-run mode.

---

## 4) Simple Web Scraper

### Goal
Scrape public web page content and save extracted values.

### Requirements
- Fetch HTML from a public page.
- Parse with `BeautifulSoup`.
- Save results to CSV or JSON.

### Stretch
- Add pagination and duplicate filtering.
